# Reacts Compilado — versões

Aqui ficam só os instaladores do **Reacts Compilado**, o app da Prota Games que monta vídeos de react a partir de compilados. O código não está aqui.

- **Windows:** baixe `Reacts-Compilado-Setup-<versão>.exe` no [último release](https://github.com/Prota-Tech/reacts-compilado-releases/releases/latest).
- **Linux:** baixe `Reacts-Compilado-<versão>.AppImage`. Só esse formato se atualiza sozinho.

O app só funciona com login Google **@protagames.com**. Depois de instalado, ele se atualiza sozinho a partir deste repositório. Ele só aceita uma versão quando o `latest.yml` está assinado pela chave da Prota Games.
